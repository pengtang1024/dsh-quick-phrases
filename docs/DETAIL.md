# 快捷短语

## 它做什么

在会话输入框附近加一排短语按钮（`继续`、`提交`、`推送`、`发版` …）。点一下按钮就把这条短语的**发送内容**直接发出去；按钮上显示的是**显示名称**。两者分开，所以按钮可以很短，真正发出去的话可以很长。

**点按行为可以改**（默认是「直接发送」）：

- **直接发送（默认）**：输入框为空、也没有附件时，一次点按就发出这条短语。
- **填入输入框**：只把内容写进草稿，发不发由你决定。

两种模式下，如果输入框里**已经有你正在写的内容或附件**，点按都不会覆盖它——改为把短语插到光标处。

## 放在哪里

短语行的位置可以在设置页里随时切换，切换立即生效：

| 位置 | 插槽 | 说明 |
| --- | --- | --- |
| 输入框下方（默认） | `conversation.composer.dock` | 常驻在输入卡片下方的一整行，最宽松，适合放多条。 |
| 输入框上方 | `conversation.input.dock` | 输入卡片上方的一整行。宽度与居中按宿主 dock 卡的几何（`--dsh-composer-card-max-width` / `--dsh-composer-side-clearance` / `--dsh-composer-dock-inset`）计算，左右和卡片的文字内边对齐；也排在排队条、待办面板之上，不会把它们和卡片拆开。 |
| 工具行右侧 | `conversation.input.right` | 挤进输入框底部的工具行（`+`、权限、模型选择那一行），只为把按钮贴近光标；空间有限，超出的短语横向滚动。 |

三条短语行都会注册，但同一时刻只渲染选中的那一条，切换是一次重渲染，不需要重载页面。

## 收起与隐藏

短语行不该挡着打字，所以可以临时收起，也可以在设置里选它常驻的形态：

- **手动收起**：点行尾的 `收起 ▾`，整排缩成一个小胶囊 `▸ 快捷短语`；点胶囊临时展开，再点「收起」收回去。
- **自动收起**（默认）：设置里「输入框有内容时」选「自动收起」——输入框里一有文字或附件就缩成胶囊，草稿清空后自动展开；也可以选「保持显示」，让整排常驻。

收起状态下点开胶囊再点短语，行为和展开时完全一样：输入框里已有内容时仍然插到光标处，不会覆盖草稿。

设置里的 **短语行显示** 把整排的形态收成一个三态下拉：

- **显示整排**：常驻一整排，行尾「收起」仍可临时折叠；
- **收成胶囊**：整排只留一个小胶囊，胶囊仍在输入框旁，点一下就能展开；
- **彻底隐藏**：整排从界面完全消失，**连胶囊都不留**，界面上什么都不显示。之后只能回到 **设置 → 快捷短语** 把下拉改回前两项（选「彻底隐藏」时旁边会标出「整排已隐藏」）；改回「显示整排」时会顺带清掉折叠状态，直接回到整排。

行尾「收起 ▾」等价于选「收成胶囊」。这个三态下拉不另存状态键：它由 `dsh.quick-phrases.hidden.v1`（优先）与 `dsh.quick-phrases.collapsed.v1` 推出，切换时组合写这两个既有键。

单条短语可以在管理页用每张卡片右上角的**眼睛**开关隐藏：隐藏后这条按钮不再出现在短语行，卡片仍留在管理页并标注「已隐藏」，再点一次恢复显示。

## 管理短语

打开 **设置 → 快捷短语**。页面分两层：上面是五项行为设置，下面是短语列表。

**行为设置**（选中即生效，无需重启）。五项的可选值、默认值与作用如下：

| 配置项 | 可选值 | 默认值 | 作用 |
| --- | --- | --- | --- |
| 显示位置 | 输入框下方 / 输入框上方 / 工具行右侧 | 输入框下方 | 决定短语行出现在哪个输入框插槽；切换后立刻移动，各位置的细节见上文「放在哪里」。 |
| 点按短语时 | 直接发送 / 填入输入框 | 直接发送 | 「直接发送」在输入框为空且无附件时，一次点按就发出这条短语；「填入输入框」只把内容写进草稿。两种模式在已有文字或附件时都改为插到光标处，不覆盖草稿。 |
| 短语行显示 | 显示整排 / 收成胶囊 / 彻底隐藏 | 显示整排 | 控制整排的常驻形态：「收成胶囊」只留一个可展开的小胶囊；「彻底隐藏」连胶囊都不渲染，只能回本页改回前两项。选「显示整排」会同时清掉折叠状态。详见上文「收起与隐藏」。 |
| 管理入口 | 文字按钮 / 齿轮图标 / 隐藏入口 | 文字按钮 | 行尾「管理」的呈现方式；齿轮图标的无障碍名称仍是「管理」，点击行为不变。「隐藏入口」不再渲染管理按钮，但短语行照常使用，管理页仍可从本页进入。 |
| 输入框有内容时 | 自动收起 / 保持显示 | 自动收起 | 草稿或附件出现时是否把整排缩成胶囊；「自动收起」在草稿清空后会自动展开，「保持显示」让整排常驻。 |

**短语列表**（一条短语一张卡片）：

- **拖动排序**：按住左侧的手柄上下拖动，松手即落到新位置；也可以用卡片右侧的 **↑ / ↓** 一格一格挪。列表顺序就是短语行里按钮的从左到右顺序。
- **显示名称**：卡片顶部那行就是按钮文字，直接点进去改（例如 `提交`）。
- **发送内容**：下面的大输入框，支持多行。
- **按钮预览**：每张卡片底部实时显示这个按钮长什么样、会发送多少字，方便检查名称是否太宽。
- **眼睛**：隐藏或恢复这一条短语。隐藏后按钮从短语行消失，卡片留在管理页并显示「已隐藏」徽标。
- **✕**：第一次点击只是把按钮变成「确认」，4 秒内再点一次才真正删除，避免误删。
- **新增短语**：追加一条空卡片并自动把光标放到名称上；**恢复默认**点一次进入确认态，再点一次恢复为内置的四条短语。

改动即时保存、即时生效，无需重启。短语保存在本机浏览器存储里（`localStorage` 键 `dsh.quick-phrases.v1`，位置存在 `dsh.quick-phrases.placement.v1`，点按行为存在 `dsh.quick-phrases.click.v1`，收起状态存在 `dsh.quick-phrases.collapsed.v1`，自动收起选项存在 `dsh.quick-phrases.autohide.v1`，整排彻底隐藏的状态存在 `dsh.quick-phrases.hidden.v1`，管理入口样式存在 `dsh.quick-phrases.manage.v1`），按 DSH 的 Web 端存储隔离，换机器或清空站点数据会丢失。「短语行显示」下拉不占新键，读写的就是 `hidden.v1` 与 `collapsed.v1`。

## 在输入框旁直接打开

短语行最右侧的 **管理** 会跳到同一页设置（收起成胶囊时，先点胶囊展开）。管理入口可以在设置里换成齿轮图标或隐藏；隐藏后行尾不再出现管理按钮，从 **设置 → 快捷短语** 进入即可。如果当前界面还没装上设置入口，会提示「请在『设置 — 快捷短语』中管理」。

## 样式

按钮、输入框、卡片全部使用宿主的语义色 token（`--dsw-alias-*`、`--dsw-radius-*`、`--dsw-focus-*`），跟随 DSH 的深色 / 浅色主题；主按钮的前景色取 `--dsw-alias-label-primary-foreground`，与宿主 Button 的 primary 变体一致，两种主题下都保证对比度。

## 边界

- 短语是纯文本；不解析变量、不执行命令。
- 只在会话输入框附近出现，不影响后台任务和计划任务。
- 语言跟随 DSH 界面语言（中文 / English），默认四条短语也按语言生成本地化文本。
