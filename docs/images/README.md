## 生成方式

```bash
ELECTRON_RUN_AS_NODE=1 "/opt/DSH NEXT/dsh-desktop-next" test/preview.mjs --shot
```

产物在 `/tmp/dqp-*.png`；裁掉多余留白后覆盖本目录对应文件即可。

## 为什么不用真机截图

真机截屏会连带把不该公开的东西一起拍进去，例如：

- 侧边栏里的会话标题、工作区/项目名（往往带客户或未发布产品名）；
- 左下角的账号标识、头像、组织名；
- 输入框里正在写的草稿、附件名、路径；
- 状态行的 token 用量、模型名、后台任务数等运行信息。

示意图只包含本插件自己的界面和一组演示短语（继续 / 提交 / 推送 / 发版），不含任何本机数据，可以放心随仓库公开。

## 需要真机图时

> 确实需要真机观感时，按下面任一条做，**不要**直接 `agkit shot` 全窗截图就提交：

1. 裁剪到只有输入卡片 / 设置面板本体，去掉侧边栏、顶栏、状态行、账号区；
2. 或者用一份干净的演示 profile（空白工作区、没有真实会话）来截；
3. 提交前逐张放大确认：没有会话名、路径、账号、token、邮箱、内网地址。

审图清单也写在 `CONTRIBUTING.md` 的「截图与隐私」一节。
